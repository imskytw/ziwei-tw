# 紫微斗數繁體開源版：Windows 安裝與使用教學

這是一套免費、開源的紫微斗數排盤網站，依倪海廈《天紀》體系排盤，全繁體中文（台灣用語）。它裝在你自己的電腦上執行，不需要註冊、不需要付費，你的資料也不會上傳。

專案網址：https://github.com/imskytw/ziwei-tw


## 這套網站有什麼

- 命盤斷語：674,976 張命盤（國曆 1950–2026 年每一天 × 12 時辰 × 男女），每張 13 個面向，共 8,774,688 段解讀、正文約 204 億字（原作者統計），解壓後 56.6 GB。排完盤就能讀，不需要 AI。
- 倪師《天紀》原話 1,848 條，每條附原影片時間點。
- 古籍節錄 75 段（骨髓賦、紫微斗數全集、全書），可全文搜尋。
- 台灣 22 縣市、368 鄉鎮市區的經度，用來校正真太陽時。
- 台灣 1945–1979 年夏令時間與日治時期時區提醒。
- 可自由選擇串接 ChatGPT、Claude、Gemini、DeepSeek，或免費的 Ollama 本機模型做 AI 問答與合盤。

56.6 GB 的斷語不會一次下載。你排到哪一年出生的盤，程式才下載那一年（約 2 MB），之後存在電腦裡。


## 第一部分：開始前你需要準備

- 一台 Windows 10 或 Windows 11 電腦（設定 → 系統 → 關於 可以看版本）。
- 網路連線（第一次安裝要下載約 200 MB 的套件）。
- 大約 1 GB 的硬碟空間。
- 電腦的系統管理員權限（安裝 Node.js 時會跳出確認視窗）。
- 第一次安裝約 10 到 15 分鐘，之後每次開啟只要幾秒。


## 第二部分：選一種安裝方式

- 方式 A：一行指令。最快，複製一行貼上就會自動完成全部步驟。推薦大部分人使用。
- 方式 B：交給 AI。如果你有 Claude 桌面版、Codex、Cursor 這類能操作電腦的 AI，把一段提示詞貼給它。
- 方式 C：手動下載。不想碰指令的話，照步驟下載、解壓縮、雙擊。


### 方式 A：一行指令

1. 打開「PowerShell」：按鍵盤左下角的 Windows 鍵（開始），輸入 PowerShell，按 Enter。會出現一個藍色或黑色的視窗。不需要「以系統管理員身分執行」。
2. 複製下面這一行（整行，一個字都不要漏）：

```
irm https://raw.githubusercontent.com/imskytw/ziwei-tw/main/install.ps1 | iex
```

1. 在 PowerShell 視窗裡按滑鼠右鍵（或 Ctrl + V）貼上，再按 Enter。
2. 如果電腦還沒有 Node.js，會用 Windows 內建的 winget 自動安裝，過程中可能跳出「是否允許此 App 變更你的裝置」，按「是」。
3. 接著會下載專案（約 6 MB）並安裝套件，畫面會跑很多字，大約 1 到 3 分鐘，請耐心等待。
4. 出現「AI 設定精靈」時，照「第三部分」回答。不想用 AI 就直接按 Enter 跳過。
5. 最後瀏覽器會自動打開網站，看到「排出你的紫微命盤」就完成了。
6. 專案會放在 C:\Users\你的名字\ziwei-tw，桌面上也會多一個「紫微斗數」捷徑。


### 方式 B：交給 AI 幫你裝

1. 打開 https://github.com/imskytw/ziwei-tw/blob/main/docs/AI安裝提示詞.md
2. 複製灰色框裡的整段文字。
3. 貼給能操作你電腦的 AI（例如 Claude 桌面版開啟電腦使用功能），它會一步一步完成安裝並打開網站。
4. AI 設定精靈要你貼金鑰時，請你自己貼，不要讓 AI 代填。


### 方式 C：手動下載

步驟 1：安裝 Node.js（網站的執行環境）

1. 打開 https://nodejs.org/zh-tw/download
2. 選 LTS（長期支援）版本，作業系統選 Windows，下載 .msi 安裝檔。
3. 雙擊下載的 .msi，一路按「Next」，看到「Automatically install the necessary tools」勾選框時不要勾，最後按「Install」，跳出權限確認按「是」。
4. 確認安裝成功：按開始鍵輸入 cmd 打開「命令提示字元」，輸入 node -v 按 Enter，顯示 v22.15 以上的數字就成功了。

步驟 2：下載專案

1. 打開 https://github.com/imskytw/ziwei-tw
2. 按頁面上方綠色的「Code」按鈕，選最下面的「Download ZIP」。
3. 下載完成後，打開「下載」資料夾，對 ziwei-tw-main.zip 按右鍵 →「全部解壓縮」→「解壓縮」。不要直接在壓縮檔裡面雙擊執行，會失敗。
4. 把解壓縮後的資料夾移到你習慣的地方，例如「文件」。

步驟 3：雙擊啟動

1. 打開資料夾，雙擊「啟動紫微斗數.bat」。
2. 如果出現藍色的「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。如果防火牆詢問是否允許 Node.js：勾「私人網路」，按「允許」。
3. 第一次會安裝套件，大約 1 到 3 分鐘。
4. 出現 AI 設定精靈時，照「第三部分」回答。
5. 瀏覽器自動打開網站就完成了。


## 第三部分：AI 設定精靈怎麼回答

第一次啟動時，黑色命令視窗裡會出現設定精靈，一題一題問你：

1. 「請輸入編號 1–6」：輸入你要用的 AI 編號（1 ChatGPT、2 Claude、3 Gemini、4 DeepSeek、5 Ollama、6 其他），按 Enter。不想用 AI 就直接按 Enter，之後隨時可以再設定。
2. 「請貼上金鑰」：貼上第四部分申請到的金鑰，按 Enter。為了安全，畫面只會顯示一排圓點，這是正常的。
3. 「模型名稱」：直接按 Enter 用預設值即可。
4. 「網站名稱」：直接按 Enter 用「紫微命盤」，或輸入你想要的名字。
5. 看到「已儲存設定」就完成了，網站會接著啟動。

之後想換 AI 或換金鑰：先關掉黑色命令視窗，雙擊「設定AI.bat」重新回答，再雙擊啟動檔。


## 第四部分：申請 AI 金鑰（想用 AI 才需要）

排盤和斷語解讀完全不需要 AI。只有「AI 問答」（自由追問）和「合盤分析」需要。下面挑一家就好，不確定就先選 Gemini 試用。

先知道兩件事：第一，這裡說的「API 金鑰」跟你平常付費訂閱的 ChatGPT Plus、Claude Pro 是分開的，要另外申請、另外計費。第二，金鑰等同密碼，只會存在你電腦上專案資料夾裡的 .env.local 檔案，不要貼到任何網站或傳給別人。


### ChatGPT（OpenAI）

1. 打開 https://platform.openai.com 並登入（可以用你原本的 ChatGPT 帳號）。
2. 到帳單（Billing）頁面先儲值一點額度，例如 5 美元。沒有餘額時 AI 會回應「餘額不足」。
3. 打開 https://platform.openai.com/api-keys ，按建立新金鑰（Create new secret key），名稱隨意，例如「紫微」。
4. 畫面會顯示一串 sk- 開頭的文字，按複製。這串只會顯示一次，關掉就看不到了。
5. 回到設定精靈選 1，貼上金鑰。


### Claude（Anthropic）

1. 打開 https://console.anthropic.com 並註冊或登入。
2. 到帳單（Billing）頁面儲值額度。
3. 打開 https://console.anthropic.com/settings/keys ，按建立金鑰（Create Key）。
4. 複製 sk-ant- 開頭的金鑰，同樣只顯示一次。
5. 回到設定精靈選 2，貼上金鑰。


### Gemini（Google）

1. 打開 https://aistudio.google.com/apikey ，用 Google 帳號登入。
2. 按建立 API 金鑰（Create API key），選一個 Google Cloud 專案（沒有的話照畫面建立一個）。
3. 複製 AIza 開頭的金鑰。Gemini 通常有免費額度，適合先試用。
4. 回到設定精靈選 3，貼上金鑰。


### DeepSeek

1. 打開 https://platform.deepseek.com 註冊登入，先儲值。
2. 到 API keys 頁面建立金鑰，複製 sk- 開頭的文字。
3. 回到設定精靈選 4，貼上金鑰。


### Ollama 本機模型（免費、不用金鑰）

1. 到 https://ollama.com/download 下載並安裝 Ollama。
2. 打開黑色命令視窗，輸入 ollama pull qwen3 按 Enter，等模型下載完成（大約幾 GB，看網速要幾分鐘到幾十分鐘）。
3. 回到設定精靈選 5，模型名稱直接按 Enter。
4. 需要電腦效能夠好（建議 16 GB 記憶體以上），回答速度會比雲端 AI 慢。


## 第五部分：網站怎麼用


### 排一張命盤

1. 網站打開後按「開始排盤」，或點上方的「排盤」。
2. 填國曆生日（年、月、日）。
3. 選出生地：先選縣市，再選鄉鎮市區。選得越細，真太陽時校正越準；不知道就選縣市即可。
4. 填出生時間（出生證明上的時間）。下方會即時顯示換算後的時辰，例如「未時」。
5. 如果出生那天台灣正在實施夏令時間，會出現黃色提醒。出生證明上的時間通常是當時的鐘錶時間，按「減 1 小時」；如果你已經自己換算過，就不要按。按錯可以按「復原」。
6. 不知道出生時間就勾「不知道出生時間」，會用子時排盤（準確度較低）。
7. 選性別，按「排盤」。


### 看命盤

- 左邊是十二宮命盤，每格寫著宮名、天干地支、主星（大字）、輔星與煞星（小字），主星旁的小字「廟、旺、陷」是亮度。
- 祿、權、科、忌四化標在星曜旁邊的小圓標。
- 命盤上方可以切換「本命」「大限」「流年」，流年可以按左右箭頭換年份。
- 點任何一個宮位，右邊的解讀會跳到相對應的面向。


### 斷語解讀（不用 AI）

- 右邊預設是「斷語解讀」，有 13 個面向：命格總覽、性格、感情、事業、財運、健康、兄弟、子女、遷移、交友、田宅、福德、父母。
- 第一次查某一年出生的盤，需要連網下載那一年的資料（約 2 MB），大約 5 到 10 秒；之後就存在電腦裡，秒開。
- 只涵蓋國曆 1950 到 2026 年出生的命盤，範圍外會提示改用 AI。
- 想更深入，按右下角「請 AI 深入解讀」，會切到 AI 問答並針對目前的面向提問。


### AI 問答

- 切到「AI 問答」分頁，AI 會先給命格總覽，下方輸入框可以自由追問，例如「今年適合換工作嗎？」。
- 右上角的「AI」標籤：綠燈代表已設定好，黃燈代表還沒設定或金鑰有問題，點一下可以看說明。


### 合盤、倪師原話、百科、古籍

- 合盤：填兩個人的出生資料，按分析，AI 會依倪師體系分析感情、合夥、親子或朋友的契合度與相處建議（需要 AI）。
- 倪師原話：1,848 條倪海廈《天紀》課程原話，可以搜尋（例如「化忌」「夫妻宮」），也能依主星、宮位、四化分類瀏覽；點時間會開啟原影片的那一秒。
- 百科：依主星、宮位、四化、格局分類整理的倪師原話入口。
- 古籍：骨髓賦、紫微斗數全集與全書的重點節錄，可全文搜尋。
- 首頁右上角可以切換亮色、暗色。


## 第六部分：之後每次使用、更新與移除

- 開啟：雙擊桌面的「紫微斗數」捷徑，或專案資料夾裡的「啟動紫微斗數.bat」。
- 使用期間不要關閉黑色命令視窗，關掉網站就停了。
- 關閉：直接關掉黑色命令視窗。
- 網址通常是 http://localhost:3456；如果被別的程式佔用，會自動換成 3457 等，以視窗上顯示的為準。
- 更新到最新版：重新執行一次方式 A 的一行指令；你的 AI 設定和已下載的斷語都會保留。
- 移除：刪除整個 ziwei-tw 資料夾與桌面捷徑即可。Node.js 若不再需要，可以到「設定 → 應用程式」解除安裝。


## 第七部分：遇到問題怎麼辦

- 網頁顯示「無法連上這個網站」：網站沒有在執行。確認黑色命令視窗還開著；關掉了就重新雙擊啟動檔。
- 打開網址看到的是別的網站：你的電腦有其他程式佔用了那個埠。看視窗上「網址：」那一行顯示的位址。
- 雙擊 .bat 閃一下就關掉：Node.js 沒裝好，或裝完還沒重新開機。照方式 C 步驟 1 安裝後，重新開機再試。
- PowerShell 出現紅字「已停用指令碼執行」：請確定你貼的是整行 irm … | iex，不要把它另存成 .ps1 檔執行。
- winget 找不到：較舊的 Windows 10 沒有 winget，請照方式 C 步驟 1 手動安裝 Node.js，再貼一次一行指令。
- 套件安裝失敗（出現紅字 ERR）：通常是網路不穩，關掉視窗重新雙擊啟動檔即可，它會自動接著安裝。
- AI 說「尚未設定金鑰」：執行「設定AI」填入金鑰，再重新啟動。
- AI 說「金鑰不正確或沒有權限」：金鑰複製不完整或已被刪除，到該服務重新建立一把。
- AI 說「用量超過上限或帳戶餘額不足」：到該服務的帳單頁面儲值，或換一家 AI。
- AI 說「找不到模型」：該服務的模型名稱更新了。執行「設定AI」，在「模型名稱」填入該服務目前的模型名稱。
- AI 說「連不上 Ollama」：確認 Ollama 已開啟（Mac 選單列或 Windows 右下角有羊駝圖示），沒有的話打開 Ollama 應用程式。
- 斷語解讀顯示下載失敗：第一次查某一年需要連網，確認網路後重新整理頁面。
- 海外出生：出生地選「海外」裡的國家和城市（28 國、105 個城市），填當地鐘錶時間即可，時差與當年的夏令時間會自動換算。清單裡沒有的城市，選同一個時區裡最近的城市。


## 第八部分：安全與隱私

- 排盤在你的瀏覽器裡完成，生日不會上傳到任何資料庫。
- 只有按下 AI 問答或合盤時，命盤內容與你的問題才會送到你自己選的 AI 服務；選 Ollama 的話資料完全不離開電腦。
- 金鑰只存在專案資料夾的 .env.local，不會上傳到 GitHub，也不要分享給別人。
- 本網站沒有廣告與流量追蹤。
